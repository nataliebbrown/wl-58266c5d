# Original-language data — sources and licenses

Generated by `scripts/build-original-language.mjs`.

- **Hebrew OT and Greek NT text, transliterations, English glosses, Strong's tags, and grammar codes**
  — STEPBible Data: TAHOT and TAGNT, created by www.STEPBible.org based on work at Tyndale House, Cambridge.
  Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source: https://STEPBible.github.io/STEPBible-Data
- **Brief lexicons** — STEPBible TBESH (Hebrew) and TBESG (Greek, based on Abbott-Smith). CC BY 4.0.
- **In-depth Greek lexicon** — Liddell-Scott-Jones, formatted by STEPBible (TFLSJ). CC BY 4.0.
- **Grammar descriptions** — STEPBible TEHMC / TEGMC morphology code expansions. CC BY 4.0.
- **In-depth Hebrew** — Strong's Hebrew Dictionary (1890, public domain) as corrected by the
  [Open Scriptures Hebrew Lexicon](https://github.com/openscriptures/HebrewLexicon), plus its
  Brown-Driver-Briggs outline (a work in progress).

Changes made: texts were split by chapter using English versification; Ketiv-only (OT) and
non-Nestle-Aland (NT) readings were left out; lexicon HTML was converted to plain text and long
entries shortened; an occurrence index (first 400 verses per word) was added.
